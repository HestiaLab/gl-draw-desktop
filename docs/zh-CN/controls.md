# GLDraw 操作指南

以下是编辑器的默认操作方式。

## 工具快捷键

| 工具 | 按键 |
|---|---|
| 选择 | `V` |
| 抓手 / 平移 | `H` |
| 线段 | `L` |
| 矩形 | `R` |
| 椭圆 | `E` |

## 文件快捷键

| 操作 | 按键 |
|---|---|
| 新建文档 | `Ctrl+N` |
| 打开 | `Ctrl+O` |
| 保存 | `Ctrl+S` |

## 编辑快捷键

| 操作 | 按键 |
|---|---|
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` / `Ctrl+Shift+Z` |
| 剪切 | `Ctrl+X` |
| 复制 | `Ctrl+C` |
| 粘贴 | `Ctrl+V` |
| 全选 | `Ctrl+A` |

## 视图快捷键

| 操作 | 按键 |
|---|---|
| 放大 | `Ctrl+Plus` |
| 缩小 | `Ctrl+Minus` |
| 缩放适配 | `Ctrl+0` |

## 指针行为

| 操作 | 行为 |
|---|---|
| 形状工具 | 在画布上左键拖拽创建对象 |
| 选择工具 | 点击选中对象 |
| 切换选中 | `Shift+点击` |
| 移动选中对象 | 拖拽已选中的对象 |
| 抓手工具 | 左键拖拽平移画布 |
| 鼠标滚轮 | 以光标位置为中心缩放 |
