# GLDraw Controls

These are the default controls for the editor.

## Tool Shortcuts

| Tool | Key |
|---|---|
| Select | `V` |
| Hand / Pan | `H` |
| Line | `L` |
| Rectangle | `R` |
| Ellipse | `E` |

## File Shortcuts

| Action | Key |
|---|---|
| New document | `Ctrl+N` |
| Open | `Ctrl+O` |
| Save | `Ctrl+S` |

## Edit Shortcuts

| Action | Key |
|---|---|
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` / `Ctrl+Shift+Z` |
| Cut | `Ctrl+X` |
| Copy | `Ctrl+C` |
| Paste | `Ctrl+V` |
| Select all | `Ctrl+A` |

## View Shortcuts

| Action | Key |
|---|---|
| Zoom in | `Ctrl+Plus` |
| Zoom out | `Ctrl+Minus` |
| Zoom to fit | `Ctrl+0` |

## Pointer Behaviour

| Action | Behaviour |
|---|---|
| Shape tools | Left-drag creates objects on the canvas |
| Select tool | Click to select |
| Toggle selection | `Shift+Click` |
| Move selected | Drag selected objects |
| Hand tool | Left-drag pans the canvas |
| Mouse wheel | Zoom at cursor |
