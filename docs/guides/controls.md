# 操作与快捷键

以下是编辑器的默认操作。快捷键可在 `gldrawdesktop.keymap.json` 中调整。

## 工具快捷键

| 工具 | 按键 |
| --- | --- |
| 选择 | `V` |
| 平移 | `H` |
| 直线 | `L` |
| 矩形 | `R` |
| 椭圆 | `E` |

## 文件

| 操作 | 按键 |
| --- | --- |
| 新建文档 | `Ctrl+N` |
| 打开 | `Ctrl+O` |
| 保存 | `Ctrl+S` |
| 另存为 | 文件菜单 |
| 导出为 PNG | 文件菜单 |
| 退出 | `Alt+F4` |

## 编辑

| 操作 | 按键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` / `Ctrl+Shift+Z` |
| 剪切 | `Ctrl+X` |
| 复制 | `Ctrl+C` |
| 粘贴 | `Ctrl+V` |
| 删除 | `Delete` / `Backspace` |
| 全选 | `Ctrl+A` |

## 视图

| 操作 | 按键 |
| --- | --- |
| 放大 | `Ctrl+Plus` |
| 缩小 | `Ctrl+Minus` |
| 适应窗口 | `Ctrl+0` |
| 键盘快捷键 | `Shift+Slash` |

## 指针行为

| 操作 | 行为 |
| --- | --- |
| 形状工具 | 在画布上左键拖拽创建对象 |
| 选择工具 | 点击选择对象 |
| 切换选择 | `Shift+Click` |
| 移动所选 | 拖拽所选对象 |
| 平移工具 | 左键拖拽平移画布 |
| 鼠标滚轮 | 以光标为中心缩放 |
| 右键 | 打开画布上下文菜单 |
